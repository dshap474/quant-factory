# references/ — source material

Read-only inputs the signal is designed against or replicates: papers, reference
implementations, public documentation you may redistribute and feature-provider
reporting-clock notes. Keep licensed books and vendor docs out of git; cite them instead. Never
edited to match an implementation — when code and reference disagree, the code is wrong or the
discrepancy is written up, in that order.

Material here is the outermost oracle: `verification/` checks cite it for known-answer values.
